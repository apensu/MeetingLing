# 会议铃铛（MeetingLing）

一个轻量、悬浮置顶的 macOS 演讲倒计时器。做演讲 / 放映幻灯片时，把它拖到屏幕角落，始终浮在画面之上，随时提醒你剩余时间。

## ✨ 功能

- **双击即运行**：原生 Swift + AppKit，无第三方依赖，体积小（约 640 KB）。
- **始终置顶**：即使在 PowerPoint / Keynote 全屏放映模式下也不会被遮挡。
- **可拖动**：按住窗口任意位置拖到屏幕任意角落。
- **一键开始 / 暂停 / 继续**：单击窗口即可切换。
- **默认 30 分钟倒计时**：到 0 会响一声提示，之后继续往下走（**允许负数**，超时后数字变红）。
- **右键菜单**：预设 30 / 45 / 60 分钟，或自定义「分钟 + 秒」；以及退出。
- **状态一目了然**：右下角显示「未开始 / 暂停」，运行中不显示文字。
- **显示格式**：`MM:SS`，超过 60 分钟自动变 `H:MM:SS`。

## 🖥 系统要求

- macOS 11（Big Sur）或更高版本
- Intel（x86_64）与 Apple Silicon（arm64）通用

## 📦 下载与使用

1. 到 [Releases](../../releases) 下载最新的 zip 包（如 `MeetingLing-1.1.zip`）并解压。
2. 把 `会议铃铛.app` 拖到「应用程序」或桌面。
3. **首次打开**（因为未做苹果官方公证）：右键点 app →「打开」→ 再点「打开」。之后双击即可直接运行。
4. 启动后默认 30:00，出现在屏幕右上角。

### 操作

| 操作 | 效果 |
|------|------|
| 双击 app | 启动 |
| 按住窗口拖动 | 移动位置 |
| 单击窗口 | 开始 / 暂停 / 继续 |
| 右键窗口 | 设定时长（预设 30/45/60 分钟 或 自定义）、退出 |

## 🔧 从源码构建

需要 macOS 上的 Xcode 或 Command Line Tools（自带 `swiftc`）。

```bash
cd CountdownTimer
./build.sh          # 生成通用版（arm64 + x86_64）的 ../会议铃铛.app
```

如需重新生成图标（可选，需先修改脚本中的 `.ico` 路径）：

```bash
python3 make_icon.py
```
